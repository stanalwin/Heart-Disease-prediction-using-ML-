# Heart-Disease-prediction-using-ML-
This project focuses on the development of a machine learning-based heart disease prediction system designed to assist in the early detection and prevention of cardiovascular diseases. Since heart disease remains one of the leading causes of death worldwide, the ability to accurately predict potential cardiac conditions using clinical data can significantly improve healthcare decision-making and preventive treatment strategies.

The project involved detailed analysis and preprocessing of the Heart Disease UCI dataset, which contains patient medical attributes such as age, sex, chest pain type, blood pressure, cholesterol levels, fasting blood sugar, ECG results, maximum heart rate, exercise-induced angina, and other clinical parameters. Data cleaning, normalization, feature engineering, and exploratory data analysis were performed to improve model performance and prediction accuracy.

Multiple supervised machine learning algorithms were implemented and compared to identify the most effective classification model for predicting the presence of heart disease. The algorithms used in the project include:

* Logistic Regression
* Naive Bayes
* Support Vector Machine (SVM)
* K-Nearest Neighbours (KNN)
* Decision Tree
* Random Forest
* XGBoost
* Artificial Neural Network using Keras

The models were trained and evaluated using Python libraries such as Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn, XGBoost, and Keras within a Jupyter Notebook environment. Performance evaluation was carried out using accuracy scores, confusion matrices, ROC curves, classification reports, and feature importance analysis.

Among all implemented models, the Random Forest classifier achieved the highest prediction accuracy of approximately 95%, demonstrating strong reliability in identifying heart disease risk based on patient data. Comparative model analysis helped determine the strengths and limitations of each algorithm in terms of accuracy, interpretability, and prediction consistency.

The project also included visualization of data distributions, correlation heatmaps, model comparison charts, and performance metrics to provide deeper insights into the dataset and prediction results. The overall system demonstrates the effectiveness of machine learning techniques in healthcare analytics and highlights the potential of AI-driven solutions in supporting early diagnosis and medical decision-making.
